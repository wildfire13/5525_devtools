# v0.3.0: 境界比較と人工QAの分離

## 対象と設計

- 基点: 5525_devtools a2b26c6、save-lab v0.2.0。
- 公式参照: wildfire13/5525 22e0b190ec0bb88d9438ef19487e587cd7e82b95。2026-11-07の照合時点のmainと一致。vendorの30ファイルをmanifestのSHA-256と照合し、変更なし。
- 期限失敗文言の修正候補は別のゲームPR。修正候補の結果をこの固定参照版の結果として扱わない。最新ゲームの自動取り込みや任意エンジンの読込は行わない。
- ③は読み取り専用レポートを維持。原本A・作業B・立ち絵を変えず、入力の過去へ巻き戻さない。地点変更は公式departの既存予測だけ。
- ④は入力セーブを受け取らない別機能。公式create/acceptによる人工状態だけを22件の既定ケースとして新規QAフォルダへ出力する。時刻と場所は直接設定し、通し実プレイとは区別する。
- 実セーブ、個人情報、PC固有設定は公開コード・配布物へ含めない。

## 機能の確認

- 単発受注中は該当イベントの境界のみ、未受注は全予定、通常依頼は境界比較対象外。カブ3・窯6・車輪12境界。
- 各境界は同じ入力から独立実行。基準より前はnot_run。繰返し実行による時間累積なし。
- 窯20h、車輪24/36hの既知の段階表示/納品処理差を、実際に受渡が成立した場合だけ警告。場所違い・荷物担当不在を成功扱いしない。
- 経路到着のstageは到着stateから取得。出発時stageと混同しない。
- 窯21 fired、22 cooling、23 returnedを表示。23h後日談の納品完了済み・イース限定条件を明記。
- 人工QAは受注中18件、未受注3件、窯の19h納品済み23h後日談1件。rollback・荷物は公式APIで生成し、時刻・場所・elapsedHoursの整合と公式保存再読込を確認。
- QA出力は既存ディレクトリ・既存ファイル・symlinkを拒否。各ファイルを排他的に新規作成。途中失敗はINCOMPLETEマーカーを残す。
- 各セーブのSHA-256と固定参照SHA、ケース条件、実納品判定、gameUi:not_runをmanifestへ記録。ゲームのプロフィールへ自動配置しない。

## UIの方針

Product Designの監査手順と、既存README記載のUnslop参照版を使用。今回の変更は情報追加に限り、既存UIの緑アクセント、灰色のタブ、表主体を維持する。

- Product: 原本を守りつつ、5525の時間条件と再現用データを調べる道具。
- Character: 正確、落ち着いた、実務的。
- World: 条件と実結果を並べる検証用の作業台。
- Moments: 境界前後の判定差と、人工データであることがすぐ読める区分。
- Signature: 原本A・作業B・検証コピー・人工QAを一貫して区別。

境界比較は③へ追加し、ゲーム用人工セーブは④へ分離。通常保存と人工QAを同じ操作にまとめない。古い結果は入力変更時に消去し、警告は行を選択して全文を確認できる。長い表は横・縦スクロールを持つ。生成操作とTEST ONLYの要点は固定し、ケース一覧・生成結果・詳細な注意は可視スクロール内に置く。一覧自体を圧縮せず、最小幅で先頭2行が実際の表示領域に入る検証を行う。

## Windows確認

RC1: Node6種・doctor、GUI27/27・既存timeline24/24・従来GUI20/20は合格。目視で1000×720の④ケース一覧が潰れる問題を検出。ケース一覧をスクロール内に置き、生成操作を固定する修正と、先頭2行の画面内bboxチェックを追加。Pythonテスト自身の日本語JSON読込でcp932エラーも検出し、UTF-8を明示。既存ファイル/フォルダ保護をsymlinkテストから分離した。

RC2最終結果（Windows / Python 3.13.17 / Tk 8.6.15 / Node.js 26.12.1）:

- 標準cp932親プロセスでPython55件: 52成功、実link fixture3件のみ理由付きSKIP（hardlink1、symlink2）、終了コード0。通常ファイル/フォルダ拒否は独立テストで成功。SKIPは合格ではなく、その環境での実link未検証を示す。
- 新GUI33/33、実cmd起動経由34/34成功。1000×720・1180×812・FHD内1880×1000で確認。
- 1000×720の④は先頭4行ほどが表示され、先頭2行bboxが表示領域内。生成前・人工ソース読込後・全22件生成後に確認。固定注意と生成ボタンはスクロール中も可視。詳細末尾・生成パス・実ゲーム未検証の結果へ到達できる。
- ③の境界表、20h境界差、窯21/22/23h段階、再計算・タブ戻りも確認。現在地と到着時刻の違いを表示。
- 全22件生成、取消、同名拒否、出力SHA不変、A/B・Undo・人工原本不変を確認。
- 既存Node6種・doctor、従来GUI20/20・timeline GUI24/24はRC1と対象コード一致を確認して結果を継承。RC2は67/67配布ファイルが試験後もZIPバイト一致。
- テストは実Tk callbackと実cmd起動後の目視。ファイル選択は人工パスのmockを使い、手動マウス操作・OSファイル選択ダイアログそのものは未実施。
- RC2差分の独立再レビューも修正指摘なし。正式版は検証済みRC2からREADME・この検証記録のみ更新し、製品コードとテストは同一。
